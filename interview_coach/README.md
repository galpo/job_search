# Interview Coach

Prep materials organized by interview type and company.

## Suggested Structure

```
/interview_coach
  /stories             ← STAR-format stories keyed to competencies
  /questions           ← role-specific questions + your answers
  /company-research    ← per-company prep briefs
  /debrief             ← post-interview notes
```

## Common Question Bank

- Tell me about yourself (2-min version)
- Why this role / company?
- Biggest GTM launch you've led?
- How do you position a complex technical product to non-technical buyers?
- Describe a time you had to build from scratch with no playbook.
- What does "category creation" mean to you, and how have you done it?
