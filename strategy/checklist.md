# Ritee's Job Search Checklist

---

## HOW TO USE
Copy the **Per-Role Checklist** below for each new company.
Check boxes off as you complete each step.
The **Master Workflow** at the top is your reference — don't edit it.

---

## Master Workflow (reference only)

### Phase 1 — Find & Evaluate
- [ ] Found a role → save JD to `jds/[company]_[role].txt`
- [ ] Run `/score-role`
- [ ] **REVIEW: Scorecard** — move forward? (Yes / No / Maybe)
- [ ] Tier 1/2 (65%+)? → Add to `active_roles.md` + Notion
- [ ] Tier 3 / Skip? → Archive scorecard, move on

### Phase 2 — Apply
- [ ] Run `/tailor-resume [company]`
- [ ] **REVIEW: Resume** — approve or revise?
- [ ] Identify contact: Hiring Manager or VP People/Recruiter?
- [ ] Run `/draft-outreach [firstname] [company]`
- [ ] **REVIEW: Message** — approve version A, B, or blend?
- [ ] Email → Gmail draft created → send
- [ ] LinkedIn → saved to `outreach/[firstname]_[company].md` → send DM
- [ ] Update contact file + Notion (status: Outreach sent)

### Phase 3 — Interview Prep
- [ ] Response received → update Notion status
- [ ] **Open Granola before every call**
- [ ] Run `/interview-prep [Company]`
- [ ] **REVIEW: Prep guide** — approve or adjust?
- [ ] Review STAR stories for this role
- [ ] Review competitor snapshot
- [ ] Prepare 5 questions to ask them

### Phase 4 — Debrief
- [ ] Interview done → run `/debrief [Company]`
- [ ] **REVIEW: Debrief** — approve or adjust?
- [ ] Update `active_roles.md` + Notion (status: Interviewing / Follow-up / Closed)
- [ ] Send thank-you within 24hrs? → Template 5
- [ ] Next round? → Loop back to Phase 3

### Phase 5 — Offer or Move On
- [ ] Offer received → evaluate vs `master_profile.json`
- [ ] Negotiate if needed
- [ ] Accept → update all files, archive pipeline
- [ ] No offer / rejected → Template 6 → Archive
- [ ] Ghosted (7+ days silence) → Template 4 (one follow-up) → Archive if no response
